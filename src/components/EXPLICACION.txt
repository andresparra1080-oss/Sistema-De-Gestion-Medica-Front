Capa: src/components/

Responsabilidad:
Los componentes en esta carpeta son piezas UI reutilizables y atómicas, diseñadas para ser independientes, fáciles de probar y consistentes con Tailwind CSS.

Buenas prácticas:
- Mantener los componentes pequeños y enfocados en una sola responsabilidad.
- Preferir props claras y tipadas (o documentadas) para evitar ambigüedad.
- Reutilizar componentes y no duplicar lógica visual.
- Evitar que los componentes conozcan detalles del backend directamente.
- Usar composición para crear layouts más complejos a partir de piezas pequeñas.
