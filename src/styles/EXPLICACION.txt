Capa: src/styles/

Responsabilidad:
La carpeta styles centraliza los estilos globales de la aplicación, incluyendo las directivas base de Tailwind CSS, variables de tema, paleta visual y estilos reutilizables para componentes y layouts.

Buenas prácticas:
- Mantener Tailwind como fuente principal de estilo.
- Usar clases utilitarias para consistencia visual y rapidez de desarrollo.
- Evitar CSS customizado excesivo cuando Tailwind pueda resolverlo.
- Definir colores, tipografías y sombras en un solo punto para mantener coherencia.
- Mantener los estilos globales limpios, legibles y orientados a la marca del producto.
