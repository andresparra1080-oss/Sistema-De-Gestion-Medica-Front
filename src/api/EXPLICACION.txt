Capa: src/api/

Responsabilidad:
La capa api encapsula toda la comunicación con el backend REST en C++. Aquí se configura el cliente HTTP, se centralizan los interceptores y se definen funciones para consumir endpoints de negocio sin mezclar lógica de UI en los componentes.

Buenas prácticas:
- Usar una única instancia del cliente HTTP para todos los servicios.
- Centralizar la URL base en VITE_API_URL para facilitar despliegues.
- Manejar interceptores para tokens, cabeceras, errores globales y logging.
- Separar la lógica de petición del código de presentación.
- Evitar llamadas directas desde páginas o componentes a endpoints raw.
