Capa: src/context/

Responsabilidad:
El contexto global centraliza el estado compartido de la aplicación, como autenticación, sesión del usuario, preferencia de tema o cualquier estado que deba llegar a varios niveles del árbol de componentes.

Buenas prácticas:
- Mantener el estado global mínimo y necesario.
- Proveer un API clara para consumo desde componentes y hooks.
- Usar Context API para datos compartidos sin sobrecargar props.
- Considerar una solución más compleja si la aplicación crece enormemente.
- Asegurar que los providers estén bien anidados y con estados consistentes.
