Capa: src/types/

Responsabilidad:
Esta carpeta define las interfaces, tipos y contratos de datos que representan la estructura JSON enviada por la API en C++ y que consumirá el frontend.

Buenas prácticas:
- Mantener los modelos sincronizados con la API para evitar errores de serialización.
- Preferir nombres descriptivos y propiedades obligatorias bien definidas.
- Documentar campos complejos con comentarios cuando el JSON no sea trivial.
- Separar modelos por entidad (usuario, paciente, inventario, diagnóstico, etc.).
- Reutilizar tipos en hooks, pages y servicios para mejorar consistencia.
